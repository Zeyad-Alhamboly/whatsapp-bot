# Hefny Accounting — WhatsApp Auto-Transaction Bot

هذا البوت يقوم بمراقبة جروب واتساب معين وتلقي صور إيصالات الدفع (مثل إيصال Axis)، ثم استخراج البيانات منها بالذكاء الاصطناعي (Gemini) وتسجيلها كمعاملة "صرف" تلقائياً في قاعدة البيانات.

## طريقة العمل (Workflow)

```
جروب الواتساب ──(صورة إيصال)──> البوت ──(تحميل الصورة)──> Gemini AI OCR ──(JSON)──> Supabase ──> تحديث الـ Dashboard
```

---

## متطلبات التشغيل

1. **Node.js** (الإصدار 18 أو أعلى)
2. **رقم واتساب مخصص** (يُنصح بعدم استخدام رقمك الشخصي لتفادي مخاطر الحظر)
3. **مفتاح Gemini API** (مجاني من [Google AI Studio](https://aistudio.google.com/))
4. **رابط مفتاح Supabase Service Role** (لتخطي سياسات الحماية RLS وتسجيل المعاملات مباشرة)

---

## خطوات التشغيل لأول مرة (Local Setup)

### 1. تثبيت الحزم (Dependencies)

افتح مبوب الأوامر (Terminal) داخل مجلد البوت وقم بتشغيل:

```bash
cd whatsapp-bot
npm install
```

### 2. إعداد المتغيرات البيئية

قم بأخذ نسخة من ملف `.env.example` وتسميتها `.env`:

```bash
cp .env.example .env
```

افتح ملف `.env` وقم بملء البيانات:

- `SUPABASE_URL`: رابط مشروعك على Supabase.
- `SUPABASE_SERVICE_KEY`: مفتاح الـ **service_role** (وليس anon_key) من إعدادات الـ API في Supabase.
- `GEMINI_API_KEY`: مفتاح Gemini الخاص بك.
- `TARGET_GROUP_ID`: معرّف الجروب المستهدف. يمكنك كتابة معرّف واحد أو عدة معرّفات مفصولة بفاصلة `,` إذا كنت تريد مراقبة أكثر من جروب (مثال: `120363321526487920@g.us,120363321526487921@g.us`).
- `ALERT_PHONE_NUMBER`: رقم الهاتف الذي يستقبل إشعارات الأخطاء عبر الواتساب (مثال: `201012345678`).

### 3. تشغيل البوت وربط الواتساب

قم بتشغيل البوت باستخدام الأمر:

```bash
npm start
```

سيظهر لك **QR Code** في شاشة الأوامر (Terminal):
1. افتح تطبيق الواتساب على هاتفك.
2. اذهب إلى **الأجهزة المرتبطة (Linked Devices)**.
3. اضغط على **ربط جهاز (Link a Device)** وقم بمسح الكود من الشاشة.

بمجرد إتمام المسح، سيقوم البوت بحفظ الجلسة في مجلد `auth_info` ولن تحتاج لمسح الكود مرة أخرى في المرات القادمة.

## كيفية معرفة معرّف الجروب (TARGET_GROUP_ID)

1. بعد تشغيل البوت بنجاح، قم بإرسال أي رسالة داخل جروب الواتساب المستهدف.
2. ستجد معرّف الجروب (ID) يظهر في شاشة الـ Terminal للبوت بتنسيق مشابه لهذا:
   `[RECV] jid=120363410816016358@g.us | isGroup=true | sender=... | type=...`
3. انسخ هذا المعرف وضعه في ملف `.env` أمام متغير `TARGET_GROUP_ID`. يمكنك وضع معرف واحد أو كتابة عدة معرفات مفصولة بفاصلة `,`:
   ```env
   TARGET_GROUP_ID=120363410816016358@g.us,120363410816016359@g.us
   ```
4. أعد تشغيل البوت (`Ctrl+C` ثم `npm start`). الآن لن ينظر البوت لأي رسائل سوى القادمة من الجروبات المحددة فقط.

## آلية الأمان ومنع التكرار

1. **الرقم المرجعي (Reference ID):** يقوم البوت باستخراج الرقم المرجعي لكل عملية دفع. إذا تم إرسال نفس الصورة مرتين أو إيصال يحمل نفس الرقم، سيرفض البوت المعاملة فوراً ويرسل رسالة تحذيرية في الجروب لتجنب التكرار.
2. **أرقام المحافظ غير المسجلة:** إذا تم إرسال إيصال برقم محفظة مرسِل غير متطابق مع أي حساب مسجل في لوحة التحكم، سيرد البوت في الجروب بوجود خطأ، وسيقوم بـ:
   - إرسال رسالة تنبيه للرقم المحدد في `ALERT_PHONE_NUMBER`.
   - تسجيل المحاولة الفاشلة في جدول `whatsapp_transactions` في قاعدة البيانات للمراجعة.
